# About This Repository
# Welcome to my SolaviseTech Women in Data (SWID) Cohort 3 learning repository!

I created this repository to document my progress throughout the SWID program, keep my assignments and projects organised, and build a portfolio that shows what I learn and what I can do with data.

For me, this program is more than attending online sessions. It is an opportunity to develop practical skills, learn from mentors and fellow participants, challenge myself with hands-on tasks, and become more confident in using data to understand problems and communicate useful insights.

As I move through the program, I will use this repository to share my work, reflect on what I have learned, and show my progress from the foundations of Python to data analysis, visualization, and machine learning.
What Is SWID?
SolaviseTech Women in Data (SWID) is a learning program designed to guide participants through key data skills, practical projects, professional development, and collaborative learning.

SWID Cohort 3 runs from October to December 2026, with live sessions scheduled for Saturdays and Sundays from 8:00 to 10:00 PM West Africa Time (WAT). The cohort roadmap includes the following learning stages:
1. Orientation and setup
2. Python foundations
3. Data analysis and visualization
4. Machine learning
5. Career development
6. Hackathon
7. Demo day and graduation
The program combines learning with practice. Participants are expected to attend sessions, complete assignments, ask questions, work respectfully with others, and document their learning journey.
What I Aim to Achieve
By the end of this program, I aim to have moved beyond simply understanding data concepts to applying them in practical situations.

# My main goals are to:
- Build a solid foundation in Python: Understand variables, operators, control flow, data structures, and functions, and use them to solve practical problems.
- Learn to analyse data: Use tools such as NumPy and pandas to explore datasets, clean data, and prepare information for analysis.
- Create meaningful visualisations: Develop charts and communicate findings in a clear, understandable way.
- Understand machine learning: Learn the difference between supervised and unsupervised learning, and gain practical experience training and evaluating models.
- Complete practical projects: Apply what I learn through assignments and mini-projects, and document the work in this repository.
- Build a professional data portfolio: Organise my work on GitHub so that mentors, peers, and potential employers can see my progress and practical skills.
- Improve my professional presence: Share honest reflections about my learning journey on LinkedIn, including lessons learned, challenges, and completed work.
- Strengthen collaboration and communication: Learn from mentors and fellow participants, contribute to group activities, and explain my work with greater confidence.
- Contribute to the final hackathon: Work with a team to develop a project, prepare a pitch, and present our solution during the program's final stage.
Ultimately, I want to finish SWID with stronger technical skills, completed projects I can explain confidently, and a clearer understanding of how I can use data to solve real-world problems.
